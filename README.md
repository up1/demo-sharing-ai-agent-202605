# Demo :: AI Agent for Coding
* Frontend with Flutter
* Backend with NodeJS and Express 
* Database with SQLite in node:sqlite
  * https://nodejs.org/api/sqlite.html

## Features
- User Authentication (Sign Up, Login, Logout)

## Create and config projects

* Frontend login
```
$flutter create frontend
$cd frontend
$flutter pub add go_router dio
$flutter test
$flutter run
```

* Backend login
```
$mkdir backend
$cd backend
$npm init -y
$npm install express jsonwebtoken bcrypt
$npm install --save-dev nodemon jest supertest
$npm test
$npm start
```
